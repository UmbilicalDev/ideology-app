# Context

## Glossary

### Election
A specific electoral call in one country (e.g. Spanish general election of 23 July 2023). The model supports many elections; the MVP loads only Spanish general elections.

### Party
A ballot ticket in an Election: a single party or an electoral coalition (e.g. Sumar), exactly as it appeared on the ballot. Splits after the election are ignored for that Election. Inclusion rule for the MVP: the ticket holds seats in the Congreso de los Diputados as a result of the previous general election. For the 2023 test data, the 2023 results are used.

### Source Document
A document that states a Party's positions for an Election, normally its election manifesto (programa electoral). Registered by an Operator as an uploaded file or a URL. A URL document whose content changed is replaced by a new one; the old one stays for the Evidence of older Dataset Versions.

### Statement
A short, neutral proposition the user rates (e.g. "The minimum wage should rise faster than inflation"). Statements are generated by the AI from the Source Documents.

### Questionnaire
The ordered set of Statements for one Election in one Dataset Version.

### Answer
The user's rating of a Statement on a 5-point scale (strongly disagree, disagree, neutral, agree, strongly agree) or `skip`. An Answer may be marked Important.

### Important
A flag the user sets on an Answer; that Statement counts double in the Match Score.

### Party Position
The AI-extracted stance of a Party on a Statement, on the same 5-point scale, or `no stance`. Every non-`no stance` Party Position carries Evidence.

### No Stance
The Party's Source Documents do not address the Statement. The Statement is excluded from that Party's Match Score and shown as "no stance in the manifesto".

### Evidence
A verbatim quote from a Source Document plus its locator (page and/or URL) that justifies a Party Position. Visible to the user.

### Dataset Version
An immutable snapshot of one Election's Questionnaire and Party Positions produced by one Pipeline Run. Share Links reference a Dataset Version.

### Pipeline Run
One execution of the AI process that generates Statements and Party Positions from Source Documents, followed by Validation.

### Validation
Automatic checks a Pipeline Run's output must pass before it is published. There is no human review or manual editing.

### Published
State of the Dataset Version currently served to users for an Election. At most one per Election at a time (none before the first passing run). Set automatically when a Pipeline Run passes Validation; the version it replaces becomes superseded.

### Match Score
Percentage affinity between a user's Answers and a Party's Positions.

### Share Link
A URL that encodes the Dataset Version and the user's Answers so the result can be reopened or shared without server-side storage.

### Operator
The person who runs the system: registers Elections, Parties and Source Documents, and triggers Pipeline Runs. Cannot edit AI output.

### Generation Mode
Configuration that decides when Pipeline Runs happen: `precomputed` (the Operator triggers runs; static data is served) or `live` (a Pipeline Run is queued automatically when a Source Document is added or its content changes, and executed by the Operator's queue command, `ideology pipeline run-queued`). Neither mode generates per user.

## Rejected / Ambiguous Terms

### Question
Use `Statement`. Reason: users rate propositions, they do not answer open questions.

### Program / Manifesto
Use `Source Document`. Reason: a manifesto is the usual case, but the concept covers any registered source.

### Result
Use `Match Score` for a single party and "results" only for the full ranking screen.
